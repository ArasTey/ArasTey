## <img src="https://raw.githubusercontent.com/twitter/twemoji/master/assets/svg/1f4cc.svg" width="22" valign="middle"/> A little more about me

- 🔓 I build **circumvention tooling** — VPN clients, config optimizers and relay panels that keep the internet reachable under heavy censorship
- ☁️ Most of my infrastructure runs on **Cloudflare** — Workers, D1 and Durable Objects, deployed without a single backend server of my own
- 🧠 **Persian-first** by default — RTL layouts, native copy and responsive design, not an afterthought bolted onto an English-first project
- 🔒 **Privacy is architecture, not a setting** — client-side when possible; when a credential must leave the browser, it never reaches it
- 🤝 Built by community request, shipped on community feedback — I answer DMs and act on feature ideas
