## <img src="https://raw.githubusercontent.com/twitter/twemoji/master/assets/svg/1f4cc.svg" width="20"> About Me

- 🔓 I build **circumvention tooling** — VPN clients, config optimizers and relay panels
- ☁️ My infrastructure lives on **Cloudflare** — Workers, D1, Durable Objects; zero servers of my own
- 🧠 **Persian-first** — RTL layouts and native copy, never an afterthought
- 🔒 **Privacy is architecture, not a setting** — client-side when possible; when a credential must leave the browser, it never reaches it
- 🤝 I answer DMs and ship community-requested features

## <img src="https://raw.githubusercontent.com/twitter/twemoji/master/assets/svg/1f680.svg" width="20"> Featured Builds

**[ArasClient](https://github.com/ArasTey/ArasClient)** — A modern VPN client for Android.
*Smart Connect races every server and picks the fastest; global auto-sort re-ranks subscriptions after each test; the custom `.arasc` container shares configs that can connect but never be extracted.*

**[cf-optimizor](https://github.com/ArasTey/cf-optimizor)** — A CDN config optimizer that never leaves your browser.
*Paste configs or a subscription link and inject CDN, fingerprint, cipher-suite and final-mask parameters in one click. 100% offline.*
